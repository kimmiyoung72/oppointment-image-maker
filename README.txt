김미영 고객관리 앱 2차 버전

기능
- 고객 등록·검색·전화
- 고객별 상담 기록
- 약속 안내 이미지 생성·저장·공유
- 담당자명·연락처·문구·색상 직접 변경
- 데이터는 사용 중인 스마트폰 브라우저에 저장

업데이트 방법
1. ZIP 압축을 풉니다.
2. GitHub appointment-image-maker 저장소에서 기존 index.html, manifest.webmanifest, service-worker.js, icon 파일을 새 파일로 교체합니다.
3. Commit changes를 누르면 Vercel이 자동 재배포합니다.
